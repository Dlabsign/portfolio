### ICY - GOAT

This project focused on the user interface and user experience (UI/UX) design, as well as the website development for **Icy Goat**, a travel agency platform offering affordable holiday packages. The primary target audience for Icy Goat is couples seeking memorable, simple, yet adventurous vacation experiences.

The main focus of this website design is ease of access to information, intuitive navigation, and a visual appeal that inspires users to start planning their trips immediately.
