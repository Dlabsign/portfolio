# Daniel Kurnia — Portfolio

A modern, high-performance, minimalist personal portfolio and design engineering showcase built with **Next.js 15**, **React 19**, **Tailwind CSS**, and **Framer Motion**.

## 🚀 Overview

- **Minimalist & Editorial Design**: Refined typography, warm monochrome aesthetics, and Swiss broadsheet-inspired layouts.
- **Interactive Work Case Studies**: In-depth breakdowns of production systems with fluid responsiveness and clean architecture.
- **Master Data Governance (MDG) Simulation**: Functional enterprise-grade dashboard, approval workflows, material catalogs, and interactive modals.
- **Retro Arcade Experience**: Integrated browser game arenas and fluid micro-animations.
- **Multilingual Support**: Seamless English (EN) and Indonesian (ID) language switching.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router, React 19)
- **Styling**: Tailwind CSS, Vanilla CSS
- **Animations**: Framer Motion physics, Lenis smooth scrolling
- **Icons**: Lucide React
- **Language**: TypeScript

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/Dlabsign/portfolio.git

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## 🏗️ Build & Production

```bash
# Production build
npm run build

# Start production server
npm run start
```
